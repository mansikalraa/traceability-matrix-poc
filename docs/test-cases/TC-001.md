# TC-001 — Validate DICOM MRI Upload

## Objective

Verify that a valid DICOM MRI study can be uploaded.

## Preconditions

- A valid DICOM MRI dataset is available.
- User has permission to upload an MRI study.

## Steps

1. Open the MRI upload page.
2. Select a valid DICOM MRI dataset.
3. Start the upload.
4. Wait for processing.

## Expected Result

The MRI study is successfully uploaded and becomes available for processing.
